# RabTech AI/ML Internship — Task 02

## Customer Churn Prediction: Problem Framing & Responsible Data

This project explores responsible machine learning for customer churn prediction.

## Deliverables

1. `reports/problem_framing_memo.md` — problem framing and decision criteria.
2. `reports/responsible_data_card.md` — dataset quality, privacy, provenance, and limitations.
3. `notebooks/baseline_notebook.ipynb` — data checks, majority-class baseline, and Logistic Regression comparison.
4. `reports/risk_register.md` — risks, mitigations, monitoring, and rollback conditions.

## Dataset

The starter dataset was provided through RabTech Academy task materials. It contains only 12 records. Its consent, license, sampling method, and feature timing have not been independently verified.

The CSV is intentionally excluded from this public repository until redistribution permission is confirmed.

## Limitations

This is an educational prototype, not a production-ready model. Results from 12 records cannot establish reliable real-world performance. Human review and proper data permissions are required before any real-world use.
